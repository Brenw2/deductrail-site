# deductrail-site

Static marketing site for [deductrail.com](https://deductrail.com) (Deductrail by Wade Works LLC).
Plain HTML/CSS served by GitHub Pages from `main`. No JavaScript, trackers, analytics or external requests.

## Layout

| Path | What it is | Edited by hand? |
| --- | --- | --- |
| `index.html`, `delete-account/index.html`, `privacy/index.html`, `404.html` | Generated pages | No: generated by `src/build.py` |
| `assets/site.css` | All styles (light and dark, from the app's design tokens) | Yes |
| `assets/fonts/` | IBM Plex Sans/Mono, self-hosted WOFF2 subsets (SIL OFL 1.1, see `OFL.txt`) | No |
| `assets/img/` | App icon, favicons, app screens (`screen-*.webp`), social image (`og.png`) | No: see below |
| `CNAME` | Custom domain `deductrail.com` (Pages needs it; don't delete) | No |
| `src/` | Site source and tooling (below) | Yes |

## Edit and rebuild

1. Change page copy or markup in `src/build.py` (header, footer and `<head>` meta live in `page()`; each page's body is a string below it). Change styles in `assets/site.css`.
2. Rebuild: `python3 src/build.py` (Python 3, no dependencies). It rewrites the four generated pages in the repo root.
3. Preview: `python3 -m http.server 8000` in the repo root, then open http://localhost:8000.
4. Commit the source change and the regenerated HTML together.

Keep the copy accurate to the app. `/delete-account/` is Deductrail's Google Play account-deletion page and must match the app's real deletion flow. `/privacy/` stays a placeholder until the privacy policy is approved for publishing.

## Deploys

GitHub Pages builds from the `main` branch, repo root (Settings → Pages). Pushing to `main` deploys, usually within a minute or two.
The custom domain is `deductrail.com` with Enforce HTTPS on; `www` and `http://` redirect to `https://deductrail.com/`. DNS is at Porkbun (apex A records to the GitHub Pages IPs, `www` CNAME to `brenw2.github.io`).
Pages serves every file in the repo, including `src/`. That's fine: it contains only site code, no secrets.

## Screenshots and images

- **App screens** (`assets/img/screen-home.webp`, `screen-trips.webp`, `screen-reports.webp`) are real screens from Deductrail's web build (Brenw2/wade-works-mileage, `npm run export:web:e2e`: local-only mode, no Supabase) filled with made-up sample data by `src/app-screens.spec.ts`. That spec runs inside a checkout of the app repo; its header has the steps. Convert the PNGs with `python3 src/screens_to_webp.py <png-dir> assets/img` (needs Pillow).
- **Social image** (`assets/img/og.png`, 1200×630) is `src/og.html` rendered by headless Chrome from the `src/` folder:
  `google-chrome --headless=new --hide-scrollbars --window-size=1200,630 --allow-file-access-from-files --screenshot=assets/img/og.png "file://$PWD/src/og.html"`
- **Icons and favicons** are copied from the app repo's `public/` and `assets/brand/` (`icon-rounded.svg`).
- **Site screenshots** for review: `node src/site-shots.js https://deductrail.com ./shots` (needs Playwright with Chromium) writes desktop and mobile full-page and above-the-fold PNGs. Don't commit them.
