# deductrail-site

Static marketing site for [deductrail.com](https://deductrail.com) (Deductrail by Wade Works LLC).
Plain HTML/CSS served by GitHub Pages from `main`. No JavaScript, trackers, analytics or external requests.

- Brand colors, icon and type (IBM Plex Sans/Mono, self-hosted, SIL OFL 1.1, see `assets/fonts/OFL.txt`) come from the app's design tokens.
- `assets/img/screen-*.webp` are real screens from the app's web build with sample data.
- `/delete-account/` is the Google Play account-deletion web resource. `/privacy/` is a placeholder until the policy is published.
